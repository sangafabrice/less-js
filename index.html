    What are accordions? Accordions are user interface components that organize content into expandable and collapsible sections. They help present large amounts of information in a compact, structured format, allowing users to reveal details only when needed.
    Which elements create a pure CSS accordion? The core of a pure CSS accordion relies on the <details> and <summary> elements, a semantic pair of tags that natively provide expand-and-collapse interaction without any scripting.
    How to group accordions? To build an accordion set, assign the same name attribute to each <details> element. This links them together so only one section stays open at a time.
    How do I open a dialog? To open a <dialog> element in non-modal mode, call the show() method. In this mode, the dialog appears without blocking interaction with the background content.
    How do I open a dialog in modal mode? To open a <dialog> element in modal mode, use the showModal() method. In this mode, a ::backdrop pseudo-element is automatically generated, and the dialog blocks interaction with the background. Focus is trapped inside the dialog by default, meaning the user can only interact with the dialog until it is closed.
    How do I close a dialog? You can close a <dialog> element programmatically using the close() method. For a pure HTML approach, place a <button> inside a <form method="dialog">; clicking the button will automatically close the dialog. By default, pressing the Esc key also closes a modal dialog.
