How to open a dialog?

The dialog element can be opened in non-modal mode using the HTMLDialogElement.show() method. In this mode the dialog does not block the background. The pseudo-element ::backdrop is not available in this mode.

How to open a modal dialog?

The dialog element can be opened in modal mode using the HTMLDialogElement.showModal() method. In this mode, the pseudo-element ::backdrop is generated, and the dialog blocks the background. Focus is trapped inside the dialog by default. This means that the user can only interact with the dialog element, and not with any other element on the page.

How to close a dialog?

The dialog element can be closed using the HTMLDialogElement.close() method. For a pure HTML method, use a button element inside a form element with method="dialog" attribute. The ESC key can also be used to close a modal dialog element by default.
